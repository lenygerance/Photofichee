# 📸 Photofichee - Système de Gestion et Traitement d'Images

Photofichee est une application web Fullstack développée avec **Django**. Elle permet de gérer, organiser et traiter des photos via une interface intuitive, tout en intégrant un système de gestion d'utilisateurs sécurisé.

## 🚀 Fonctionnalités
* [cite_start]**Gestion d'utilisateurs :** Inscription, connexion et espaces personnels sécurisés[cite: 22].
* [cite_start]**Organisation des photos :** Système d'upload, de stockage et de classement des fichiers images[cite: 22, 24].
* [cite_start]**Traitement d'image :** Intégration des modules **OpenCV** et **Pillow** pour l'optimisation et l'affichage des visuels[cite: 23].
* [cite_start]**Base de données :** Structuration des données utilisateurs et fichiers pour une performance accrue[cite: 24].

## 🛠️ Stack Technique
* [cite_start]**Back-end :** Python 3, Django[cite: 22].
* [cite_start]**Traitement d'image :** OpenCV, Pillow (PIL)[cite: 23].
* [cite_start]**Versionnage :** Git / GitHub[cite: 24].
* **Base de données :** SQLite (ou PostgreSQL/MySQL selon configuration).
