# 📸 Photofichee - Système de Gestion et Traitement d'Images

Photofichee est une application web Fullstack développée avec **Django**. Elle permet de gérer, organiser et traiter des photos via une interface intuitive, tout en intégrant un système de gestion d'utilisateurs sécurisé.

## 🚀 Fonctionnalités
* **Gestion d'utilisateurs :** Inscription, connexion et espaces personnels sécurisés.
* **Organisation des photos :** Système d'upload, de stockage et de classement des fichiers images.
* **Traitement d'image :** Intégration des modules **OpenCV** et **Pillow** pour l'optimisation et l'affichage des visuels.
* **Base de données :** Structuration des données utilisateurs et fichiers pour une performance accrue.

## 🛠️ Stack Technique
* **Back-end :** Python 3, Django.
* **Traitement d'image :** OpenCV, Pillow (PIL).
* **Versionnage :** Git / GitHub.
* **Base de données :** SQLite (ou PostgreSQL/MySQL selon configuration).
